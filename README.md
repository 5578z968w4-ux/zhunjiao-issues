# 準交 CNC 交期預估系統：問題回報

這裡只用來回報「準交 CNC 交期預估系統（Google 試算表範本版）」的問題與建議，不放程式碼。

- 作品頁與下載：https://www.tongge.tw/works/cnc/
- 安裝教學：https://www.tongge.tw/works/cnc/install.html
- 使用條款：https://www.tongge.tw/works/cnc/terms.html

## 回報前

1. 先看安裝教學的「遇到問題怎麼辦」，很多情況照表處理就能解決。
2. 記下版本號：網頁頁尾或「系統設定 → 使用資訊」，例如 `0.3.0-beta.25 · b60d3e31`。
3. 按「Issues → New issue」，選「問題回報」或「功能建議」。

## 請勿公開的內容

Issues 所有人都看得到。請不要貼上：

- 帳號密碼、Google 帳號電子郵件
- 準交網頁網址（`/exec` 結尾）、現場 QR code 或其中的密鑰
- 真實工單、品號、客戶名稱，或其他能辨識個人或公司的內容

截圖前請先遮住以上內容。

## 回應方式

範本免費提供，不附專屬客服、回應時限或可用性保證，詳見使用條款。
